### 1.7.1 The Three Levels of Pearl's Causal Hierarchy
- **Level 1: Association (Seeing): P(Y|X)**

### 1.7.2 The D-Separation Criterion on Software Causal DAGs
In a causal DAG G, a path p is blocked (d-separated) by a conditioning set Z if and only if:
1. p contains a chain i -> m -> j or a fork i <- m -> j such that the middle node m is in Z.
2. p contains an inverted fork (collider) i -> m <- j such that neither m nor any descendant of m is in Z.
In software, colliders appear naturally: two independent services write to the same Kafka dead-letter queue. Conditioning on the queue induces spurious correlation between the two services unless properly blocked.

### 1.7.3 The Back-Door and Front-Door Adjustment Formulas
To estimate the interventional distribution P(Y|do(X=x)) from observational data:
- **Back-Door Criterion:** A set of variables Z satisfies the back-door criterion relative to (X, Y) if no node in Z is a descendant of X, and Z blocks every path between X and Y that contains an arrow into X.

- **Front-Door Criterion:** Used when confounders between X and Y are unobserved, but an intermediate mediator M exists such that X intercepts all paths to M and all back-door paths from M to Y are blocked by X.
